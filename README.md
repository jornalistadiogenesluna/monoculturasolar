# Monocultura Solar

Pacote estático para GitHub Pages.

## Publicação

1. Envie `index.html` e `.nojekyll` para a raiz da branch `main`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Selecione **main** e **/(root)**.
4. Salve.

URL esperada:

`https://jornalistadiogenesluna.github.io/monoculturasolar/`
